description: "Follow up on something someone owes you or you promised"
---

Read config.yaml and voice.md from the project root.

The user wants to follow up on a commitment. $ARGUMENTS should describe
what and who.

Steps:
1. Search Gmail for the original thread with relevant keywords and person.
2. Search Slack for related messages.
3. Check if there's been any update since the commitment was made.
4. Draft a follow-up message (email or Slack, whichever channel the
   original was on).
   - Tone: friendly but clear. Reference the original ask and timeline.
   - If overdue: note it directly but respectfully.
5. Show the draft to the user for review.
