# Setup Checklist — Do This Before the Session

Complete these steps before AI Week so we can spend our time together
building, not troubleshooting logins. Should take about 10 minutes.

## 1. Confirm you have claude.ai access with Projects

- Go to [claude.ai](https://claude.ai) and log in with your work account.
- Projects require a paid plan (Pro, Team, or Enterprise). If you're not
  sure which plan you have, check with IT before the session.

## 2. Create a new Project

- In the left sidebar, click **Projects** → **Create project**.
- Name it something like "My Chief of Staff" or "Personal CoS."
- Leave it empty for now — we'll fill in instructions together during the
  session.

## 3. Connect Gmail and Google Calendar

- Inside your new Project (or in Settings → Connectors, depending on your
  workspace), find **Connectors** or **Integrations**.
- Enable **Gmail** and **Google Calendar**.
- You'll be asked to authorize access via a Google sign-in screen — this is
  normal. Approve it.
- Confirm both show as "Connected" before moving on.

## 4. (Optional) Connect Slack

- If your workspace has Slack Connector enabled, turn it on too. Not
  required for the core session, but useful if you want to try the
  advanced examples afterward.

## 5. Bring one real writing sample

- Find one email or message you've written recently that sounds like "you"
  — a couple of sentences is enough. You'll use it during the session to
  teach the tone/voice section. No need to prepare anything else; you'll
  paste it in live.

## Checklist summary

- [ ] Logged into claude.ai with a Projects-enabled account
- [ ] Created a new (empty) Project
- [ ] Gmail Connector shows "Connected"
- [ ] Google Calendar Connector shows "Connected"
- [ ] (Optional) Slack Connector shows "Connected"
- [ ] Have one real sentence/paragraph you've written on hand

## If something doesn't work

Common issues and fixes:

| Problem | Likely cause | Fix |
|---|---|---|
| Don't see "Projects" in sidebar | Not on a Projects-eligible plan | Check with IT about your license tier |
| Don't see "Connectors" option | Feature not enabled for your workspace | Check with IT/workspace admin |
| Google auth screen fails or loops | Browser blocking popups, or wrong Google account | Try again in an incognito window, make sure you're using your work Google account |
| Connector shows "Connected" but nothing comes back later | Permissions scoped too narrowly | Re-authorize and accept all requested scopes |

If you're still stuck, arrive 10 minutes early to the session and we'll
sort it out before we start.
