# Slides

Two versions of the same deck — use whichever fits how you're presenting.

## `index.html` — interactive HTML deck

Open it directly in any browser (double-click, or `open index.html`). No
build step, no server needed.

- **Arrow keys / swipe** to navigate, or click the dots/arrows at the
  bottom
- **N** toggles a speaker-notes panel (talk track per slide, matches
  `00-FACILITATOR-GUIDE.md`)
- Works fine projected full-screen (F11 / browser fullscreen) for a live
  session

## `Build-Your-Own-Personal-CoS.pptx` — PowerPoint

Use this if you need to edit slides directly in PowerPoint/Keynote/Google
Slides, or need an offline file to hand off. Speaker notes are included on
each slide (View → Notes in PowerPoint).

## Both decks

24 slides, same content and structure, generic and free of any proprietary
or company-specific information — every example uses the fictional persona
"Jordan Lee, VP of Operations, Acme Corp."
