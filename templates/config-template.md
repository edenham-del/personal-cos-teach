# Preferences Template

**This is an optional add-on, not the main file.** The main file is
`custom-instructions-template.md` — start there, and only come back to
this one once the basics are working and you notice something missing.

This covers the smaller preferences that make a personal CoS feel tailored
instead of generic — calendar habits, approval thresholds, commitment
tracking. Same two options as `voice-template.md`: attach this as a
separate knowledge file once filled in, or merge the parts you want
directly into `custom-instructions-template.md` as extra sections.

## Calendar preferences

- I prefer meetings that are [25 or 50 minutes / 30 or 60 minutes / other]
  rather than a full 30 or 60 — say which you prefer and why if you have one
- I want focus time blocks of at least [X hours], ideally on
  [morning/afternoon] and on [which days]
- Remind me [X minutes] before a meeting starts if you can, with context on
  who's attending and why

## Email/message preferences

- Categorize using: [reuse the URGENT / NEEDS RESPONSE / FYI / CAN WAIT
  buckets from your custom instructions, or define your own]
- Draft replies automatically for: [URGENT and NEEDS RESPONSE only, or
  whatever you prefer]
- Never draft automatically for: [e.g. anything involving money, legal,
  HR, or anything you want to always write yourself]

## Approvals / spending (if relevant to your role)

- Auto-flag anything above $[THRESHOLD] for my review
- Categories I always want to see regardless of amount: [e.g. travel,
  software subscriptions, contracts]

## Tracking what you owe people and what they owe you

This is optional but powerful: ask your CoS to help you track commitments
using **memory** (see `01-WHAT-IS-A-PERSONAL-COS.md` for what memory is and
how it differs from custom instructions).

- "Remember: I committed to [X] for [person] by [date]" → saved to memory,
  recallable in any future chat in this Project
- "Remember: I delegated [X] to [person] by [date]" → same, but tracks what
  you're owed
- "What do I owe right now?" / "Who owes me what?" → ask any time; it pulls
  from memory, not just the current conversation
- "Mark [commitment] as done" / "forget that commitment" → clears it out
  once it's resolved, so memory doesn't fill up with stale items

Tip: be explicit ("remember...") rather than assuming it saved something
automatically — that way you know for certain it's there when you check
back next week. If you want commitments visible somewhere beyond chat too
(a shared doc, a Slack canvas), that's a further upgrade — start with
memory, it's zero extra setup.

## Keep this list short

The instinct is to configure everything on day one. Resist it. Start with
2-3 preferences that solve a real daily annoyance, use it for a week, then
add more based on what you actually noticed was missing.
